## The joke

> I took notes during the meeting so I'd look busy. The notes just say 'this could have been an email' fourteen times.

One line, 116 characters: a joke about office life, like a line you'd send a coworker after a meeting that should have been an email.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — a constant string, no randomness, no time, no network — so repeated runs produce byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
